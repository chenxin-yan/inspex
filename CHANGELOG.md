# inspex

## 0.1.0

### Minor Changes

- [#2](https://github.com/chenxin-yan/inspex/pull/2) [`c6eddcc`](https://github.com/chenxin-yan/inspex/commit/c6eddccaa5de0952f09a1cfee8d8b3b27bfdfd8c) Thanks [@chenxin-yan](https://github.com/chenxin-yan)! - First usable version: a TypeScript 7.1 content mapper for OpenAPI 3.0 and 3.1. Import `paths`, `components` and `operations` from a `<name>.openapi.jsonc` file, in the shapes openapi-typescript emits, with no generation step. Options: `register` (add each spec to another package's interface) and `readWriteMarkers`. Requires Node.js 26 or later and TypeScript 7.1.
